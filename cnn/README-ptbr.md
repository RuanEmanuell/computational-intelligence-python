## O que é uma CNN?
Uma Rede Neural Convolucional (CNN) e uma arquitetura de rede neural especializada em processamento de imagens.

Ela aprende padroes visuais por meio de camadas convolucionais que detectam bordas, texturas e formas.
Em tarefas de classificacao, a rede mapeia imagens para probabilidades de classe.

## Implementação
Esta pasta contem uma implementacao em Python para classificacao de imagens com **5 classes**.

O script suporta dois modos de dados:
- **Modo dataset local**: carrega imagens de `cnn/dataset/<nome_da_classe>/...`
- **Modo fallback**: usa Fashion-MNIST filtrado para 5 classes (`0` a `4`)

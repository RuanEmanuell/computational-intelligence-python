## What is a Genetic Algorithm?
A Genetic Algorithm (GA) is an optimization and search technique inspired by natural selection and biological evolution.

Instead of testing all possible solutions, GA evolves a population of candidates over generations using operators such as:
- **Selection**: chooses the best individuals based on a fitness function
- **Crossover**: combines parts of two parents to generate new offspring
- **Mutation**: introduces random variations to maintain diversity

## Implementation
This folder is dedicated to Genetic Algorithm implementations in Python.

The implementation typically includes:
- Population initialization
- Fitness function evaluation
- Selection, crossover, and mutation steps
- Replacement strategy and stopping criteria
- Best-solution tracking through generations

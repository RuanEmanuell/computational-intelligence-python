## What is a MultiLayer Perceptron?
A MultiLayer Perceptron (MLP) is a class of feedforward artificial neural network that overcomes the limitations of simple Perceptrons by introducing one or more hidden layers. 

It learns using the Backpropagation algorithm, minimizing error through gradient descent:
- **Forward Pass:** Input data is propagated forward through the hidden layers using non-linear activation functions (such as Hyperbolic Tangent) to generate continuous outputs.
- **Backward Pass:** The error is calculated at the output and propagated backward to iteratively adjust weights and biases.

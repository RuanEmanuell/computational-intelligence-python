## O que é uma MultiLayer Perceptron?
A MultiLayer Perceptron (MLP) é uma classe de rede neural artificial feedforward que supera as limitações do Perceptron simples ao introduzir uma ou mais camadas ocultas (escondidas).

Ela aprende utilizando o algoritmo Backpropagation (Retropropagação), minimizando o erro através do gradiente descendente:
- **Fase Forward:** Os dados de entrada são propagados para a frente através das camadas ocultas utilizando funções de ativação não-lineares (como a Tangente Hiperbólica) para gerar saídas contínuas.
- **Fase Backward:** O erro é calculado na saída e retropropagado para ajustar iterativamente os pesos e biases.
